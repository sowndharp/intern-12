# Black Wolf Digital Studio — Premium Portfolio

Static, responsive portfolio site built with HTML, CSS and vanilla JavaScript. No paid API, framework, or build command required.

## Preview locally
Open `index.html` in Chrome or use VS Code Live Server.

## Before publishing
1. Open `script.js` and replace `YOUR_EMAIL@example.com` with a public studio contact email.
2. Open every project demo link and verify it is live and suitable to show.
3. Confirm that you have permission to display any project content, names, logos, or screenshots.
4. Project images in `assets/` are AI-generated illustrative artwork, not screenshots of the linked websites. The cards are labelled as demo/concept builds.
5. The enquiry form opens the visitor's email app; it does not store submissions. A backend or form provider is needed for a true hosted submission system.

## Deploy on Vercel
1. Put this folder in a Git repository.
2. In Vercel, choose Add New → Project and import the repository.
3. Select this folder as the root directory.
4. Choose the Other framework preset (static site); leave build command and output directory empty/default.
5. Deploy, then test the live site on desktop and mobile.

## Files
- `index.html` — page content, project cards and SEO metadata
- `styles.css` — black-and-gold responsive design
- `script.js` — mobile menu, project filters and enquiry mailto
- `assets/` — generated hero and project artwork
